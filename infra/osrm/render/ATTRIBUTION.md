# Routing data attribution

Map data © OpenStreetMap contributors, available under the Open Database License
(ODbL) 1.0: https://www.openstreetmap.org/copyright

The Israel and Palestine extract is provided by Geofabrik:
https://download.geofabrik.de/asia/israel-and-palestine.html

The exact source URL, source OSM timestamp, byte length and SHA-256 are recorded
in `map-source.json`. This deployment uses the official OSRM car.lua profile and
MLD algorithm. Keep this attribution and access to the source data when sharing
the image or derived graph. The source map is downloaded during image building;
no customer, driver or account data is embedded in the image.
